# 消息队列

## RocketMQ

### 简介

RocketMQ是阿里巴巴开源的分布式消息中间件，支持事务消息、顺序消息、延迟消息等功能。

### 依赖配置

```xml
<dependency>
    <groupId>com.alibaba.cloud</groupId>
    <artifactId>spring-cloud-starter-stream-rocketmq</artifactId>
</dependency>
```

### 生产者配置

```yaml
spring:
  cloud:
    stream:
      rocketmq:
        binder:
          namesrv-addr: rocketmq:9876
      bindings:
        order-created-output:
          destination: order-created-topic
          content-type: application/json
```

### 消费者配置

```yaml
spring:
  cloud:
    stream:
      rocketmq:
        binder:
          namesrv-addr: rocketmq:9876
        bindings:
          order-created-input:
            consumer:
              ordered: true
              tags: orderCreated
      bindings:
        order-created-input:
          destination: order-created-topic
          group: order-consumer-group
```

## 消息类型

### 普通消息

```java
@Service
public class OrderMessageService {
    
    @Autowired
    private RocketMQTemplate rocketMQTemplate;
    
    public void sendOrderCreatedMessage(Order order) {
        rocketMQTemplate.asyncSend("order-topic", order, new SendCallback() {
            @Override
            public void onSuccess(SendResult sendResult) {
                log.info("消息发送成功: {}", sendResult.getMsgId());
            }
            
            @Override
            public void onException(Throwable e) {
                log.error("消息发送失败", e);
            }
        });
    }
}
```

### 事务消息

```java
@Service
public class OrderTransactionService {
    
    @Autowired
    private RocketMQTemplate rocketMQTemplate;
    
    @Transactional(rollbackFor = Exception.class)
    public void createOrderWithTransaction(OrderCreateDTO dto) {
        // 1. 本地事务
        Order order = createOrder(dto);
        
        // 2. 发送事务消息
        Message<Order> message = MessageBuilder.withPayload(order)
                .setHeader(RocketMQHeaders.TRANSACTION_ID, "order-" + order.getId())
                .build();
        
        rocketMQTemplate.sendMessageInTransaction("order-transaction-topic", message, order);
    }
}

@Component
public class OrderTransactionListener extends RocketMQLocalTransactionListener {
    
    @Override
    public RocketMQLocalTransactionState executeLocalTransaction(Message msg, Object arg) {
        try {
            // 本地事务逻辑
            return RocketMQLocalTransactionState.COMMIT;
        } catch (Exception e) {
            return RocketMQLocalTransactionState.ROLLBACK;
        }
    }
    
    @Override
    public RocketMQLocalTransactionState checkLocalTransaction(Message msg) {
        // 检查本地事务状态
        return RocketMQLocalTransactionState.COMMIT;
    }
}
```

### 延迟消息

```java
public void sendDelayMessage(Long orderId, int delayLevel) {
    Message message = MessageBuilder.withPayload(orderId)
            .build();
    
    // delayLevel: 1s, 5s, 10s, 30s, 1m, 2m, 3m, 4m, 5m, 6m, 7m, 8m, 9m, 10m, 20m, 30m, 1h, 2h
    rocketMQTemplate.syncSend("order-delay-topic", message, 3000, delayLevel);
}
```

## 消息消费者

### 基础消费

```java
@Component
@Slf4j
public class OrderMessageConsumer {
    
    @StreamListener("order-created-input")
    public void handleOrderCreated(Order order) {
        log.info("收到订单创建消息: {}", order);
        // 处理业务逻辑
    }
}
```

### 消费重试

```java
@Component
@Slfj4
public class OrderMessageConsumer {
    
    @StreamListener(value = "order-created-input", condition = "headers['tag']=='orderCreated'")
    public void handleOrderCreated(Message<Order> message) {
        Order order = message.getPayload();
        try {
            // 业务逻辑
        } catch (Exception e) {
            log.error("消息处理失败", e);
            throw e;
        }
    }
}
```

## 消息可靠性

### 生产端可靠性

```java
// 同步发送
SendResult result = rocketMQTemplate.syncSend("topic", message);

// 异步发送 + 回调
rocketMQTemplate.asyncSend("topic", message, new SendCallback() {
    @Override
    public void onSuccess(SendResult sendResult) {
        // 成功
    }
    
    @Override
    public void onException(Throwable e) {
        // 失败，重试
    }
});
```

### 消费端可靠性

```java
@Component
@Slf4j
public class ReliableConsumer {
    
    @StreamListener("order-input")
    public void handle(Message<Order> message) {
        Order order = message.getPayload();
        try {
            // 业务处理
        } catch (Exception e) {
            log.error("处理失败，消息: {}", message);
            // 重新入队或人工处理
        }
    }
}
```

## 消息顺序

### 生产者顺序

```java
// 发送顺序消息
rocketMQTemplate.syncSendOrderly("order-topic", order, "orderId");
```

### 消费者顺序

```yaml
spring:
  cloud:
    stream:
      rocketmq:
        bindings:
          order-input:
            consumer:
              ordered: true
```
