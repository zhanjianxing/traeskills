<core_principle>
## 核心原则：报价确认书具有法律效力

报价确认书的作用：
1. **明确范围** - 详细列出项目功能范围和交付内容
2. **锁定价格** - 明确项目总价和付款方式
3. **法律效力** - 双方签字后作为合同附件，具有法律约束力
4. **避免纠纷** - 明确双方权责，减少后期纠纷

```
需求清单 + 报价书 → 整合 → 报价确认书 → 双方签字 → 合同附件
```
</core_principle>
