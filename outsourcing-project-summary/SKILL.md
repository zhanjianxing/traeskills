<core_principle>
## 核心原则：项目总结是持续改进的基础

**总结警示：**
- 不总结导致重复犯错
- 不分析导致问题反复
- 不改进导致效率低下

**核心价值：**
1. **成果记录** - 记录项目成果和价值
2. **问题分析** - 分析问题原因和解决方案
3. **经验提炼** - 提炼可复用的经验教训
4. **持续改进** - 提出改进建议优化流程

**项目总结规范（必须严格遵守）：**
```
项目总结必须包含：
1. 项目概况 → 项目背景、目标、范围、成果
2. 项目执行 → 时间线、里程碑、资源使用
3. 问题分析 → 遇到的问题、原因分析、解决方案
4. 经验教训 → 成功经验、失败教训、改进建议
5. 后续计划 → 维护计划、迭代计划、客户关系
```
</core_principle>
